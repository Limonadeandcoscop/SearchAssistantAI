# Security policy

## Supported versions

Security fixes go into the latest release of Search Assistant AI.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately through GitHub instead:
**Security → Report a vulnerability** on
https://github.com/Limonadeandcoscop/SearchAssistantAI/security.

Include the module version, the Omeka S and PHP versions, and the steps
to reproduce. You will get an answer within a few working days.
